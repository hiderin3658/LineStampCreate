# 手順書：LINEスタンプの登録から販売開始まで

最終更新: 2026-06-08
対象: LINE Creators Market で **初めて** スタンプを登録・販売する人向け
前提: 本リポジトリのスクリプトで生成した `output/<name>/<name>_line_stickers.zip`（例: `Cat1_line_stickers.zip`）が手元にある状態

> ⚠ 画面のUI・価格・分配率・審査期間は変更されることがあります。最終的な数値・操作は必ず[公式サイト](https://creator.line.me/ja/)で確認してください。本書は2026年6月時点の調査に基づきます。

---

## 0. 全体像（登録〜販売の流れ）

```
① クリエイター登録（初回のみ）
       ↓
② 入出金先（送金先）情報の登録（初回のみ・販売に必須）
       ↓
③ 新規スタンプ登録（アイテム作成）── タイトル/説明文 等
       ↓
④ 販売情報の入力 ── クリエイター名/コピーライト/カテゴリ 等
       ↓
⑤ 画像アップロード ── 生成したZIPを一括アップロード
       ↓
⑥ 販売価格の設定
       ↓
⑦ 審査をリクエスト
       ↓
⑧ 審査（数時間〜2日程度）──（リジェクトなら修正して再申請）
       ↓
⑨ 承認 → リリース（販売開始）
       ↓
⑩ タグ設定・販売状況の確認
```

- **作業環境**: PCのブラウザ（[LINE Creators Market](https://creator.line.me/ja/)）が基本。スマホだけで完結したい場合は公式アプリ「**LINE Creators Studio**」でも登録可能（ただし本リポジトリの加工済みZIPを使うならPCブラウザ＝Creators Marketが確実）。
- **ログイン**: 普段使っているLINEアカウント（メールアドレス＋パスワード）でログインします。

---

## 1. 事前に用意するもの

- [ ] LINEアカウント（メールアドレス・パスワード設定済み）
- [ ] アップロードする画像一式のZIP（`Cat1_line_stickers.zip` … `main.png` / `tab.png` / `01.png`〜`24.png` が直下に入っているもの）
- [ ] クリエイター名（販売者として表示される名前。後から全スタンプ共通で表示される）
- [ ] コピーライト表記（例: `© 2026 YourName` ※**半角英数字のみ**）
- [ ] 送金先の銀行口座情報（売上を受け取るため。②で登録）
- [ ] スタンプのタイトル・説明文（日本語＋**英語は必須**）

---

## 2. ① クリエイター登録（初回のみ）

1. [LINE Creators Market](https://creator.line.me/ja/) を開き、「**登録はこちら**」をクリック。
2. LINEに登録しているメールアドレスとパスワードでログイン。
3. クリエイター情報（名前・国・メールアドレス等）を入力して送信。
4. 届いたメール内のURLにアクセスして登録を完了。

> これで「マイページ」が使えるようになります。

---

## 3. ② 入出金先（送金先）情報の登録（初回のみ・販売に必須）

売上を受け取るために必要です。登録しないと販売開始できません。

1. マイページの「**アカウント設定**」→「**入出金先情報**」を開く。
2. 送金手段を選択（**銀行振込** または **LINE Pay**）。
3. 口座情報など必要事項を入力して保存。

> 分配金は一定額（一般に **1,000円以上**）たまると送金対象になります。詳細は公式の規定を確認してください。

---

## 4. ③ 新規スタンプ登録（アイテム作成）

1. マイページで「**新規登録**」→「**スタンプ**」を選択。
2. **スタンプタイプ**を選択（通常の静止画スタンプ）。※登録後は変更不可。
3. **言語・テキスト情報**を入力：
   - **タイトル**：言語ごとに入力。**英語は必須**（最大11言語まで設定可）。他クリエイターと重複不可、文字数制限あり。
   - **説明文**：スタンプの説明（英語表記が必要）。

---

## 5. ④ 販売情報の入力

| 項目 | 内容・注意点 |
|------|-------------|
| **クリエイター名** | 販売者名として全スタンプ共通で表示される |
| **コピーライト** | 著作権表記。**半角英数字のみ**（例: `© 2026 YourName`） |
| **カテゴリ（テイスト＆キャラクター）** | 雰囲気・キャラ種別を選択（任意） |
| **プライベート設定** | 新着・ランキングに表示するか（自分専用にするなら非公開設定） |
| **販売エリア** | 全世界（約230ヶ国）か、特定エリアのみか選択 |
| **ライセンス証明書** | 著作権の確認を求められた場合に提出（自作なら通常不要だが、確認時に活用） |

> 💡 自分のオリジナルイラストを使う限り、他者の商標・ロゴ・著名人・既存キャラクターを含めないこと（リジェクトの主因）。

---

## 5.5 「新規登録」画面の各設定項目（汎用リファレンス）

「新規登録」画面では以下の項目を設定します。各項目の意味と選び方の目安を示します（作品ごとの具体的な設定値は、クリエイター名などの個人情報を含むため**リポジトリには含めず**、ローカルで `設定内容_<作品名>.md` のように個別に用意します）。

### スタンプ詳細

| 項目 | 説明・選び方 |
|------|-------------|
| **スタンプのタイプ** | スタンプ / アニメーション / カスタム / メッセージ / BIG / ポップアップ / エフェクト から選択。通常の静止画イラストは「**スタンプ**」。⚠ **登録後は変更不可**。 |
| **スタンプ個数（1パッケージ）** | 8 / 16 / 24 / 32 / 40個 から選ぶ。アップロードする画像枚数に合わせる。スタンプ編集画面で設定でき、**審査をリクエストするまでは変更可**。 |
| **言語 / タイトル / 説明文** | **英語が基本言語**（設定していない言語は英語で表示される）。タイトル（40字以内）・説明文（160字以内）を入力。「言語を追加」で日本語など他言語を追加可。タイトルは**他クリエイターと重複不可**。※「スタンプ」の英語表記は "Sticker"。 |

### 販売情報

| 項目 | 説明・選び方 |
|------|-------------|
| **クリエイター名** | 販売者名。**全スタンプ共通**で表示。英語を基本にし、必要なら日本語を追加。一度設定すれば使い回せる（※他作品が審査中は変更不可・50字以内）。 |
| **コピーライト** | 著作権表記。**半角英数字のみ**（50字以内・全角文字/URL不可）。形式は「© または (C) ＋ 年 ＋ 名前」。例: `© 2026 YourName`。記号が弾かれる場合は `(C)` を使う。 |
| **AIの使用** | 画像生成などに**AIを使ったかを申告**する項目。使った場合は必ず「**AIを使用しています**」を選ぶ（事実どおりに申告。虚偽申告はしない）。 |
| **テイストカテゴリ** | 作品の雰囲気（かわいい / おもしろい / シンプル 等）。任意だが、設定するとユーザーに見つけられやすい。 |
| **キャラクターカテゴリ** | キャラの種別（動物 / ネコ など）。⚠ **個人名（名前・名字）を含むスタンプを売る場合は必ず「名前・名字」を選択**。含まないなら選ばなくてよい。 |
| **プライベート設定** | 「**LINE STORE/ショップ公開**」＝新着・ランキング・検索に表示。「**非公開**」＝URLを知る人だけが見られる。一般販売するなら**公開**。 |
| **LINEスタンプ プレミアム** | 定額制（使い放題）サービスへの参加可否。⚠ **「参加する」にしても、対象になるのは販売開始から180日経過後**（最初の180日は個別販売のみ）。初期値は「参加する」。露出増・分配上乗せの一方、180日後は会員が個別購入せず使える点に留意（個別販売は継続）。後から変更も可能。 |
| **販売エリア** | 「販売可能な全てのエリア」か「一部エリア」。露出を最大化するなら**全エリア**。お試し送信キャンペーンは販売エリアに日本を含む必要あり。 |
| **特集企画** | LINE主催のテーマ特集への応募。**条件に合致する作品だけ**参加する（テーマ不一致はリジェクト回避のため参加しない）。バナー掲載で露出増。各特集に**審査受付期間（締切）**があるので注意。新規スタンプのみ・大量申請や特定個人向けはNG等の共通条件あり。 |
| **スタンプアレンジ機能** | 購入者が文字などをアレンジできる機能への参加可否。文字が絵に固定されている作品は参加しない方が無難（任意）。 |
| **LINE Creators Collaboration** | 公式コラボ企画のスタンプか否か。通常は「**LINE Creators Collaborationのスタンプではありません**」。 |
| **お試し送信キャンペーン** | 購入前にお試し送信できる施策。条件（タイプがスタンプ/アニメ/BIGのいずれか・販売エリアに日本を含む・プレミアム対象・コラボ非該当・スタンプメーカー非経由）を満たせば参加でき、販売の後押しになる。 |
| **販売開始設定** | 「**手動で販売を開始**」＝承認後に自分でリリース（タイミング調整・最終確認ができ、初回におすすめ）。「**自動で販売を開始**」＝承認後すぐ販売開始。 |

> 💡 **クリエイター名・入出金先**などの「自分」に関する情報は初回のみ設定すれば使い回せます。**2作品目以降はタイトル / 説明文 / 画像 / 価格 / タグ**を中心に用意すればOKです。

## 6. ⑤ 画像アップロード（生成したZIPを使う）

1. 「**スタンプ画像**」の項目で「**ZIPで一括アップロード**」を選ぶ（個別アップロードも可）。
2. 本リポジトリで生成した `Cat1_line_stickers.zip` を選択してアップロード。
   - ZIP直下に `main.png`（メイン240×240）、`tab.png`（タブ96×74）、`01.png`〜`24.png`（スタンプ最大370×320）が入っている構成なので、自動で各枠に割り当てられます。
3. **販売個数** は画像枚数に合わせて選択（今回は **24個**）。※審査リクエスト後は個数変更不可。

> ✅ アップロード前チェック（本リポジトリの `_preview.png` で目視確認）：
> - [ ] 背景がすべて透過されている（白い汚れ・縁取りが残っていない）
> - [ ] キャラや文字が枠で切れていない
> - [ ] 各画像が最大370×320px・偶数・1MB以下、ZIPが60MB以下

---

## 7. ⑥ 販売価格の設定

- 静止画スタンプは **¥120 / ¥250 / ¥370 / ¥490 / ¥610** などの価格帯から選択。
- 初めてなら **最安の¥120** が購入されやすくおすすめ。
- 価格は販売後も変更可能。

---

## 8. ⑦ 審査をリクエスト

1. すべての必須項目（テキスト・画像・価格・送金先）が埋まっていることを確認。
2. 「**リクエスト**」ボタンを押して審査申請。

> 💡 **タグ設定は審査リクエスト後（または承認後）に行う**のがおすすめ。「デザインとタグの意味が一致しない」という理由でのリジェクトを避けられます。

---

## 9. ⑧ 審査

- **期間の目安**: 数時間〜約2日（国内向けは1日程度、海外向けは長め）。土日も進むことがある。
- **よくあるリジェクト理由**:
  - 背景の**透過漏れ・白い汚れ**（最多）→ 本リポジトリの透過処理＋`_preview.png`確認で対策。
  - **権利侵害**：ブランド/商品ロゴ、芸能人・著名人の写真、漫画/ゲームのスクショ、ネット上の拾い画像など。
  - 公序良俗に反する内容、他サービス名の使用 等。
- **リジェクト時**: 指摘箇所を修正し、再度審査リクエスト（再申請可）。
  - 画像を直す場合は、元のシート画像を修正 → 本リポジトリのスクリプトで再生成 → ZIPを差し替えアップロード。

---

## 10. ⑨ リリース（販売開始）

1. 審査通過（承認）の通知が届く。
2. マイページで対象スタンプの「**リリース**」ボタンをクリック。
   - 「承認後すぐ自動販売」か「手動でリリース」を選べる場合があります。
3. **LINE STORE / スタンプショップへの反映に1時間〜数時間** かかることがあります。

---

## 11. ⑩ タグ設定・販売状況の確認

- **タグ**（検索キーワード）: スタンプ1つにつき最大3個まで設定可能。デザインに合った語を選ぶ。
- 販売開始後は、マイページで売上・ダウンロード数を確認できます。

---

## 12. 分配金（売上の受け取り）

- クリエイターへの分配は、プラットフォーム手数料を除いた**売上の一定割合**（一般に「Apple/Googleの手数料30%を除いた額の50%」等と案内されることが多い）。
- **最新の分配率・送金条件は必ず[公式](https://creator.line.me/ja/)で確認**してください（改定されることがあります）。
- 一定額（一般に1,000円以上）たまると、登録した口座へ送金されます。

---

## 13. 申請前 最終チェックリスト

- [ ] クリエイター登録 完了
- [ ] 入出金先（送金先）情報 登録済み
- [ ] タイトル・説明文（**英語含む**）入力済み
- [ ] クリエイター名・コピーライト（**半角英数字**）入力済み
- [ ] 画像ZIPをアップロードし、24個＝価格個数を選択
- [ ] `_preview.png` で透過・切れ・汚れを目視確認済み
- [ ] 権利侵害になる要素（ロゴ・著名人・他作品）が無い
- [ ] 販売価格を設定
- [ ] （審査リクエスト後に）タグを設定
