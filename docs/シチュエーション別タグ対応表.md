# シチュエーション別タグ対応表（vol1〜3 の正本）

`docs/プロンプト_vol1〜3.txt` の各シチュエーションに対して設定するタグの**正本（マスター）**。

スタンプのタグは「どんなキャラか」ではなく「どんな言葉・場面か」で決まるため、**同じvolなら全キャラで同じタグ**になる。したがってタグは画像から毎回読み取り直すのではなく、この表を**転記**して `output/<名前>/タグ設定.md` を作るのが正しい運用（同一シリーズの全キャラでタグが完全に揃う）。

## この表の使い方・ルール

- タグは `docs/LINEスタンプ_タグ設定.md` の「利用可能タグ全一覧」に**実在する語のみ**で構成している（一覧外の語は登録できない）。
- 登録は左（上位）から優先する。**1スタンプの登録上限は最大3個**（`docs/手順書_LINEスタンプ登録から販売まで.md` 参照）。上限を超える分は関連度の低い順に落とす。
- **動物タグはキャラ依存**のため、この表には載せていない。全スタンプ共通で、そのキャラの動物タグ（猫＝`ネコ`／犬＝`イヌ` 等。一覧の「動物」カテゴリ参照）を**1つ**追加する。
- タグは画像生成プロンプト（`docs/プロンプト_vol*.txt`）には**含めない**。プロンプトに混ぜると「画像の中に文字を入れる」指示と相まって、タグ語がイラストに描き込まれる恐れがあるため、生成（プロンプト）とタグ付け（この表）は分離する。

## 関連ドキュメント

- `docs/LINEスタンプ_タグ設定.md` … タグの考え方・登録手順・利用可能タグ全一覧（この表の語の出どころ）。
- `docs/プロンプト_vol1〜3.txt` … 各volの画像生成プロンプト（シチュエーション定義。タグは含めない）。
- `output/<名前>/タグ設定.md` … 作品ごとの最終成果物（この表を転記、または画像から推定して作る）。
